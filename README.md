# Introdução sobre lógica e algoritmos

> Referência de operadores mais utilizados na estrutura da lógica de programação.

## Operadores de atribuição

```text
=   mesmo que  x = y
+=  mesmo que  x = x+y
-=  mesmo que  x = x-y
*=  mesmo que  x = x*y
/=  mesmo que  x = x/y
%=  mesmo que  x = x%y
**=  mesmo que  x = x**y
```

## Operadores lógicos

```text
&& : e
|| : ou
!  : não
```

## Operadores aritméticos

```text
+  : adição
-  : subtração
*  : multiplicação
** : exponenciação
/  : divisão
%  : restante (remanescente)
++ : incremento
-- : decremento
```

## Operadores de comparação

```text
==  : igual à
=== : valor igual e tipo igual
!=  : não é igual
!== : valor diferente e tipo diferente
>   : maior que
<   : menor que
>=  : maior ou igual
<=  : menor ou igual
?   : operador ternário
```
